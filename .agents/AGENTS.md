# Project Rules & Workspace Preferences

## Session Startup Automation
- **Auto-Start Localhost Server**: At the start of every new session in this workspace, automatically start the backend dev server (`node server.js` in `./backend`) if it is not already running.
- **Provide Localhost Link**: Immediately output the active localhost link ([http://localhost:3001](http://localhost:3001)) at the start of the conversation so the user can easily open it.
